# weak-nlp (vendored)

Weak supervision algorithms for classification and extraction tasks (CNLM/ENLM).

This package was originally published as [code-kern-ai/weak-nlp](https://github.com/code-kern-ai/weak-nlp) on PyPI. It is now vendored inside `refinery-weak-supervisor` and maintained here only.

## Usage

Installed as an editable local dependency via `pip install -e ./packages/weak-nlp`. Import as:

```python
import weak_nlp
```
